How to install

Four steps, about two minutes.

  1. Tap Install ESign above and tap Install again on the iOS pop-up. Open this page in Safari if the pop-up doesn't appear inside another app.

  2. Trust the certificate so ESign can open. Go to Settings → General → VPN & Device Management, tap Chengdu Railway Bureau, then Trust.

  3. Open ESign from your Home Screen. If iOS asks you to verify the app, keep Wi-Fi on and tap Verify — it checks the certificate online.

  4. Sign your first IPA. In ESign, import an IPA, pick the Chengdu Railway Bureau certificate (password IOSUG if asked), tap Sign, then Install.

If something goes wrong

Free certificates are shared, so these are the usual fixes.

“Unable to Verify App” or the app won't open

The certificate was most likely revoked by Apple — this happens to every free shared certificate sooner or later, and re-trusting it won't fix it.

Delete ESign, then check back here or on the UG Telegram channel (button below) — when a new free certificate drops, this page gets updated with it and you just install again.

Nothing happens when I tap Install

OTA installs only start in Safari (or the Telegram in-app browser). If you're inside another app's web view, tap the ••• menu and choose “Open in Safari”, then tap Install again.

Still stuck? Grab the signed IPA from the download link under the Install button — that file and the install manifest are hosted on this page and never expire — and install it with ESign, AltStore or SideStore instead.

Also make sure you're not in Low Data Mode and that the download isn't blocked under Settings → Screen Time → Content Restrictions.

How do I use the downloaded certificate files?

Send both files to your iPhone (AirDrop, Files, or Telegram), then in ESign go to the certificate / import section and import the .p12 and .mobileprovision together. The password is IOSUG.
